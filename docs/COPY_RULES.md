# Copy Rules

## 1. Core Copy Principle

The product should use short, gentle, action-oriented Chinese copy.

The interface should not explain too much. It should guide users through small actions.

Preferred feeling:

```text
轻一点。
慢一点。
可以回来。
可以调整。
```

## 2. Words to Avoid

Avoid these words in primary UI:

```text
失败
惩罚
清零
落后
打败
监督
考核
排名
必须
坚持到底
战胜自己
自律挑战
```

Avoid exaggerated praise:

```text
你太棒了
你是最强的
成功逆袭
燃起来了
```

Avoid guilt-inducing copy:

```text
你又中断了
你没有坚持住
你今天失败了
你落后别人了
```

## 3. Preferred Words

Use:

```text
开始
试试看
放下
调整
回来
痕迹
轻一点
第一步
自然发生
卡在哪里
这也会留下来
```

## 4. Page-Level Copy

### 4.1 Home Empty State

Headline:

```text
先种下一个容易发生的行为。
```

State chips:

```text
我很有动力
我有点累，但想开始
我只是看看
```

Primary button:

```text
生成一个微习惯方案
```

Small theory entry:

```text
为什么不是打卡？
```

Short explanation:

```text
行为发生，不只靠坚持。
它需要想做、做得动、想得起来。
这里会帮你把行为设计得更容易发生。
```

### 4.2 Home Existing State

Today card:

```text
今天只做第一步也可以。
```

Return state:

```text
欢迎回来。
今天可以从一个很小的动作重新开始。
```

Button:

```text
我回来了
```

### 4.3 Creation Page

Step 1:

```text
你想让什么变得容易一点？
```

Step 2:

```text
为什么是现在？
```

Step 3:

```text
它可能怎么发生？
```

Step 4:

```text
哪个最值得先开始？
```

Step 5:

```text
把它变成今天能开始的版本。
```

Step 6:

```text
什么时候最容易发生？
```

Final:

```text
先试运行 3 天。
```

Save button:

```text
放到我的树上
```

### 4.4 Detail Page

Today action:

```text
今天从这里开始。
```

Record options:

```text
完成真实行动
完成入场动作
今天先降级
今天没有发生
```

Missed reason:

```text
今天卡在哪里？
```

Suggestion:

```text
明天可以把它调轻一点。
```

### 4.5 Review Page

Title:

```text
看看它是怎么发生的。
```

Motivation:

```text
你更容易在有明确原因时开始。
```

Ability:

```text
动作轻一点时，它更容易发生。
```

Prompt:

```text
晚饭后的提示最稳定。
```

Suggestion:

```text
下一步可以先保留这个提示点。
```

### 4.6 Explore Page

Title:

```text
找一个更容易开始的方式。
```

Glow wall:

```text
有人今天也只是完成了第一步。
有人把计划调轻了一点。
有人中断后又回来了。
```

## 5. Microcopy Rules

Button copy should be direct:

Good:

```text
继续
放到树上
调轻一点
换提示点
回到花园
```

Bad:

```text
点击此处提交你的完整习惯设计方案
确认并进入下一阶段
```

Tooltip copy should be short:

Good:

```text
6 月 10 日：完成入场动作
```

Bad:

```text
你在 6 月 10 日完成了该习惯的初级阶段，因此系统为你记录了一片浅绿色叶子。
```

## 6. Tone by User Mode

### Gentle Companion Mode

Use:

```text
今天轻一点也可以。
这也会留下来。
回来就好。
```

### Rational Closed-loop Mode

Use:

```text
这个提示点比较稳定。
动作门槛可能偏高。
建议先降低一步。
```

### Experience Exploration Mode

Use:

```text
这条枝桠在晚饭后更容易发芽。
今天留下了一点微光。
```

## 7. Final Rule

If a sentence is not necessary for action, remove it.

If a sentence creates pressure, rewrite it.

If a sentence explains theory, convert it into an action.
