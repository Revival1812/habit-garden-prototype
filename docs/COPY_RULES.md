# Copy Rules

## 1. Core Copy Principle

The product should use short, gentle, action-oriented Chinese copy.

The interface should not explain too much. It should guide users through small actions.

Preferred feeling:

```text
轻一点。
慢一点。
可以回来。
可以调整。
今天发生什么，就先留下什么。
```

---

## 2. Deprecated Language

Do not use tree-growth language for the new home and detail system:

```text
习惯树
树枝
树干
年轮
长出叶子
浇水
养成植物
枝干生长
放到树上
```

Use river-stage language instead:

```text
河流
河面
留下痕迹
放到河流里
今天的物件
这一天在这里
```

---

## 3. Words to Avoid

Avoid these words in primary UI:

```text
失败
惩罚
清零
落后
打败
监督
考核
排名
必须
坚持到底
战胜自己
自律挑战
```

Avoid exaggerated praise:

```text
你太棒了
你是最强的
成功逆袭
燃起来了
```

Avoid guilt-inducing copy:

```text
你又中断了
你没有坚持住
你今天失败了
你落后别人了
```

## 6. Microcopy Rules

Button copy should be direct:

Good:

```text
继续
放到河流里
调轻一点
换提示点
回到花园
留下今天
```

Bad:

```text
点击此处提交你的完整习惯设计方案
确认并进入下一个阶段
```

Tooltip copy should be short:

Good:

```text
6 月 10 日：入场
```

Bad:

```text
你在 6 月 10 日完成了该习惯的初级阶段，因此系统为你记录了一片深绿色小叶片。
```

---

## 7. Tone by User Mode

### Gentle Companion Mode

Use:

```text
今天轻一点也可以。
这也会留下来。
回来就好。
```

### Rational Closed-loop Mode

Use:

```text
这个提示点比较稳定。
动作门槛可能偏高。
建议先降低一步。
```

### Experience Exploration Mode

Use:

```text
今天的痕迹停在这里。
河面上多了一点回应。
```

---

## 8. Final Rule

If a sentence is not necessary for action, remove it.

If a sentence creates pressure, rewrite it.

If a sentence explains theory, convert it into an action.
