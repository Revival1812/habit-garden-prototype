# Low Text Copy Skill

## Purpose

Use this skill to keep the interface concise and low-pressure.

The product should not explain everything through long text. The interface should guide users through small actions.

The current visual system is the river stage. Use river language for home and detail copy.

## Core Rule

Each screen should have:

* one main sentence
* one main action
* minimal helper text
* no long paragraph unless hidden behind a small explanation link

## UI Copy Style

Use:

* short Chinese sentences
* soft verbs
* action-oriented phrases
* low-pressure wording
* neutral diagnosis
* river-stage language for records

Avoid:

* academic explanation
* motivational slogans
* self-discipline preaching
* exaggerated praise
* guilt-based reminders
* tree-growth copy in home or detail

## Forbidden or Discouraged Words

Avoid in primary UI:

```text
失败
惩罚
清零
落后
排名
监督
必须
战胜自己
自律挑战
你太棒了
```

Use carefully or avoid:

```text
坚持
打卡
任务
考核
完成率
```

## Deprecated Tree Copy

Do not use these in new home or detail UI:

```text
习惯树
树枝
树干
年轮
长叶子
浇水
养植物
放到树上
```

Use river copy instead:

```text
河流
河面
痕迹
放到河流里
留下今天
这一天在这里
```

## Preferred Phrases

Use:

```text
先试试看
今天只做第一步也可以
欢迎回来
卡在哪里
这也会留下来
把它调轻一点
放到河流里
从这里开始
把今天发生的，轻轻放在河面上
```

## River Home Copy

No habit selected:

```text
把今天发生的，轻轻放在河面上。
不用追赶。先看见一个容易发生的小动作。
```

Primary action:

```text
设计一个小习惯
```

Selected habit:

```text
这个月的痕迹
```

No records:

```text
这个月还很安静。
```

Add habit:

```text
新增
```

## Today Record Copy

Panel title:

```text
今日记录
```

Helper:

```text
选择今天最接近的状态就好。
```

Statuses:

```text
完成
入场
降级
未发生
```

Optional note:

```text
想留下一点想法吗？
```

Skip:

```text
先不写
```

Save:

```text
留下今天
```

## Missed Day Copy

Good:

```text
今天卡在哪里？
```

Reason options:

```text
忘记了
太累了
时间不合适
动作太大
环境不支持
突发事件
情绪低落
不想记录原因
```

Bad:

```text
你今天没有完成目标，请选择失败原因。
```

## Detail Copy

Use:

```text
这周的痕迹
当前方案
发生节奏
这一天
收起
展开
```

Default single-day detail:

```text
点选河面上的一天，看看它留下了什么。
```

For `missed`:

```text
这一天没有发生。它也会留下来。
```

## Creation Copy

Good:

```text
你想让什么变得容易一点？
```

Final save:

```text
放到河流里
```

Bad:

```text
请在此处填写你的长期习惯目标、目标描述、预期结果以及执行周期。
```

## Completion Copy

Good:

```text
今天的痕迹留下来了。
```

Bad:

```text
你太棒了！你战胜了自己！
```

## Review Copy

Good:

```text
动作轻一点时，它更容易发生。
```

Bad:

```text
根据系统综合评估，你的行为执行能力指标在本周期内呈现波动趋势。
```

## Final Rule

If the user can act without the sentence, remove the sentence.

If the sentence creates pressure, rewrite it.

If the sentence sounds like a teacher, soften it.

If the sentence returns to tree growth, rewrite it as river-stage copy.
