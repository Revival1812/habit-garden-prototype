# Low Text Copy Skill

## Purpose

Use this skill to keep the interface concise and low-pressure.

The product should not explain everything through long text.

The interface should guide users through small actions.

## Core Rule

Each screen should have:

* one main sentence
* one main action
* minimal helper text
* no long paragraph unless hidden behind a small explanation link

## UI Copy Style

Use:

* short Chinese sentences
* soft verbs
* action-oriented phrases
* low-pressure wording
* neutral diagnosis

Avoid:

* academic explanation
* motivational slogans
* self-discipline preaching
* exaggerated praise
* guilt-based reminders

## Forbidden or Discouraged Words

Avoid in primary UI:

```text
失败
惩罚
清零
落后
排名
监督
必须
战胜自己
自律挑战
```

Use carefully or avoid:

```text
坚持
打卡
任务
考核
完成率
```

## Preferred Phrases

Use:

```text
先试试看
今天只做第一步
欢迎回来
卡在哪里
这也会留下来
把它调轻一点
放到我的树上
从这里开始
```

## Empty State Copy

Good:

```text
先种下一个容易发生的行为。
```

Bad:

```text
欢迎使用本系统，本系统将基于福格行为模型帮助你建立长期稳定的习惯养成机制。
```

## Creation Copy

Good:

```text
你想让什么变得容易一点？
```

Bad:

```text
请在此处填写你的长期习惯目标、目标描述、预期结果以及执行周期。
```

## Missed Day Copy

Good:

```text
今天卡在哪里？
```

Bad:

```text
你今天没有完成目标，请选择失败原因。
```

## Return Copy

Good:

```text
欢迎回来。
今天可以从一个很小的动作重新开始。
```

Bad:

```text
你已经连续 7 天未打卡，请重新开始。
```

## Completion Copy

Good:

```text
这片叶子留下来了。
```

Bad:

```text
你太棒了！你战胜了自己！
```

## Review Copy

Good:

```text
动作轻一点时，它更容易发生。
```

Bad:

```text
根据系统综合评估，你的行为执行能力指标在本周期内呈现波动趋势。
```

## Final Rule

If the user can act without the sentence, remove the sentence.

If the sentence creates pressure, rewrite it.

If the sentence sounds like a teacher, soften it.
