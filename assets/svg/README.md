# Habit Tree SVG Asset Pack

Generated as modular assets for data-driven tree growth.

- Branch paths use `.branch-path` for stroke-dasharray growth animation.
- Every file has a viewBox and transparent background.
- Tree overlays (`bark-texture.svg`, `trunk-highlight.svg`) align to the same `0 0 320 390` viewBox as `trunk-base.svg`.
- Leaf assets expose `.leaf`; branch assets expose `.branch` and `.branch-path`; markers expose `.marker`.
- Suggested CSS: `vector-effect: non-scaling-stroke` when scaling aggressively.
